Paso 1

Proveedores de IA

Añade los proveedores que uses; después elige uno de ellos y un modelo que ofrezca. Las credenciales se guardan en este equipo, no se vuelven a mostrar y mandan sobre .env.

Hay una limpieza en marcha. Mientras dura, los proveedores no se pueden guardar, quitar, desconectar ni actualizar. El modelo sí se puede cambiar en el paso 2: se aplicará a la próxima limpieza.
Para empezar, configura al menos un proveedor: LiteLLM (URL y API key), GitHub Copilot o Claude (con tu plan Pro/Max). Después elige el modelo más abajo. No hace falta tocar .env.
